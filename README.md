# Amazon-Sales-Dashboard
Power BI dashboard for Amazon sales performance analysis using data visualization and analytics.
This project visualizes and analyzes Amazon's sales data using **Microsoft Power BI**, providing actionable insights through interactive charts and KPIs.

---

## 🧠 Project Overview
The dashboard provides a data-driven view of:
- Total Sales, Profit, and Quantity trends  
- Product Category & Regional performance  
- Monthly revenue growth and customer purchase patterns  
- Key metrics like Profit Margin and Average Order Value  

---

## 🧩 Technologies Used
- **Power BI** – Dashboard creation, DAX measures, data visualization  
- **Power Query** – Data cleaning and transformation  
- **Excel / CSV** – Raw data source (amazon.csv)  
- **SQL** – For analytical queries and data preparation  

---

## 🌟 Key Features
- Interactive filters and drill-downs for deep insights  
- Category, regional, and customer analytics  
- Time-series and profit trend visualization  
- Clean, optimized Power BI data model
